# A practitioner-assisted migration documentation system.

I'd define the product internally as:
"A practitioner-assisted migration documentation system."
Not:
"An AI that writes migration reports."
The distinction is huge.
Our competitive advantage isn't that a computer can produce a 10-page GPR in 10 seconds.
The valuable part is:
The practitioner spends less time assembling information and more time exercising professional judgement.
